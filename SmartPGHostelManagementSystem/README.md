# Smart PG Hostel Management System

A Java-based web application for managing PG/Hostel operations digitally.

## Project Overview

Smart PG Hostel Management System helps administrators manage students, rooms, payments, complaints, notices, and visitors efficiently.

## Features

- Admin Login
- Student Management
- Room Management
- Room Allocation
- Payment Management
- Complaint Management
- Notice Management
- Visitor Management
- Dashboard Overview

## Technologies Used

- Java
- JSP
- Servlet
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat
- Eclipse IDE

## Database

MySQL database is used for storing:

- Student information
- Room details
- Payment records
- Complaints
- Visitor records
